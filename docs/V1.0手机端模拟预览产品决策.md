# V1.0 手机端模拟预览产品决策

## 目标

在不改变文章 HTML、主题渲染和微信公众号发布链路的前提下，让运营在工作台内快速判断文章在窄屏阅读场景下的节奏与视觉密度。

## 首版范围

- 预览区提供“内容校对 / 手机预览”两种视图。
- 手机预览固定使用 390px 内容宽度和单一现代手机外壳，不提供多机型切换。
- 手机外壳使用 MIT 许可的 `@sneas/telephone` SVG；项目在其透明屏幕区域内叠加本地实现的公众号阅读页顶部与底部操作栏。
- 两种视图复用同一个 iframe，切换时不重新加载文章，并保留文章内部阅读位置。
- 提供沉浸查看模式；按 `Esc` 或点击“退出沉浸”返回工作台。
- 冻结版本的最终预览使用同一套交互，避免编辑阶段与交付阶段体验割裂。
- 界面明确标注“模拟预览”，不承诺与微信客户端像素级一致。

## 非目标

- 不模拟微信客户端全部导航、菜单和真实交互，顶部与底部栏仅用于形成接近手机阅读的视觉环境。
- 不提供多机型、多屏幕尺寸选择。
- 不用手机外壳修改文章内容宽度或发布后的 HTML。
- 不替代真实微信公众号草稿箱与手机预览验收。

## 验收标准

1. 进入工作台后默认显示内容校对视图。
2. 点击“手机预览”后出现通用手机外壳，文章宽度保持 390px。
3. 连续切换两种视图时 iframe 不重载，内部滚动位置不丢失。
4. 沉浸模式覆盖当前窗口，退出后回到原工作台状态。
5. 桌面窄窗口下控件不溢出，仍可完成模式切换与沉浸查看。
6. 文章导出、复制、冻结和公众号草稿创建结果不受影响。
