# v0.1.0-alpha.29

这是 alpha.28 的累积更新：保留完整的参考图驱动主题创作、21 类组件评审及图文复制能力，并修复安装升级时可能切到另一套空数据的问题。新安装和升级统一使用此版本，不需要先安装 alpha.28。

## 安装与升级保护

- 安装前检查当前工作台实际使用的数据来源，以及已知旧目录。发现旧库有任务而新目录为空，或安装器将改变既有数据目录时，先返回迁移确认提示，不静默切库、覆盖数据或自动选择测试库。
- 升级非空数据集前，备份 SQLite、正文图片及交付资产；升级后核对任务 ID 和每个资产的 SHA-256，再确认运行中的工作台能读取原任务。不以版本一致或任务数量相同代替数据延续检查。
- 安装回执新增 `data_continuity` 与备份位置。只更新 Skill 时不顺带切换工作台；需要迁移时仍使用人工确认后的完整数据恢复流程，私密配置不进入对话或发行包。
- Windows、macOS 安装包均包含检查工具；包内测试增加“创建任务后重新安装”的真实验证，不只测试空目录首次安装。
- 补齐干净开发环境的 HTML 解析及 JSON Schema 测试依赖，避免依赖本机预装库导致 CI 收集失败。

## 验证与边界

- 本地干净环境完整回归：483 项通过、15 项按环境条件跳过，0 失败。Windows 自包含候选载荷已验证首次安装、旧数据阻断、非空升级、任务和两类资产保留及备份。
- 三个平台的正式资产由 Actions 构建，通过各自的安装与非空升级检查后发布。macOS 实际执行结果以对应 Actions 检查为准。
- 不自动迁移来源不明的数据，不修改文章事实，不自动创建微信草稿或群发。已知旧数据目录之外的离线历史安装仍需用户或 Agent 提供位置。

按 [安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/main/INSTALL_FOR_AGENT.md)安装或升级即可。alpha.28 保留为历史回退版本，常规安装入口使用 alpha.29。
