# v0.1.0-alpha.32

本次为安装与数据连续性补丁。重点是让 Windows 用户切换 Agent 后继续使用同一份历史，而不因程序目录不同打开另一套空工作台。

## Windows 跨 Agent 共享历史

- 新版正式安装统一将文章、正文图片、交付资产、自定义主题和私有配置保存在 `%USERPROFILE%\.wechat-visual-director`。程序目录仍可位于 LocalAppData，但数据不再随宿主的目录重定向分开。
- 工作台准备入口优先读取共享登记，已升级的不同程序入口转交同一套活动程序，并沿用其本地 API 地址和运行状态。
- 从旧版升级前先检查和备份数据；复制后核对任务及配套图片、主题，保留原来源。发现两份独立历史，或旧版在衔接后又写入原库时，明确提示确认，不自动合并或覆盖。
- 登记损坏、历史数据库缺失、数据位置或身份不一致时停止，不把悄悄新建空库当成启动成功。
- 默认卸载保留共享历史。删除一套非活动程序不会停止另一套活动程序或移除它仍在使用的 Skill 注册。

## 安装和复制提示

- 识别 Windows 默认目录与 Codex 的应用重定向目录，并用目录文件身份去重；真正存在多套安装时要求选择，不按文章数量或版本新旧代选。
- 浏览器拒绝剪贴板权限、限制安全策略或不支持图文格式时，给出对应的中文恢复提示，并保留下载交付包的出口，不再统一误导为图片过大。
- 数据恢复和升级备份纳入自定义主题文件。

## 升级提醒与验证边界

请让 Agent 明确执行升级，或重新运行官方安装器。仅替换 Skill 文本，不能让未升级的旧程序自动获得共享历史能力。已有多份历史时先确认来源，不要手动只复制 SQLite 文件；数据库、正文图片、交付资产和主题需要整体核对。

本次共享历史改动针对 Windows；macOS 沿用原有数据位置。发布包含 Windows x64、macOS Apple Silicon 和 Intel 安装包及 SHA-256。安装与恢复入口见 [安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/main/INSTALL_FOR_AGENT.md)。不自动迁移独立源码测试库，不自动合并冲突历史，不自动发布公众号文章。
