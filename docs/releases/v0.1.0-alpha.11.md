# v0.1.0-alpha.11

Alpha.11 把视觉主题从四套扩展到六套，并提升弱模型下的安全组件覆盖。该版本仍是本地优先的开源 Alpha，不会自动群发文章。

## 主要变化

- 新增“青春校园”和“未来科技”主题；
- 六套主题均具备独立的文章骨架、正文节奏部件和 12 类语义组件变体；
- 未来科技最终采用 `FUTURE EDITION` 科学杂志语法，减少工程线框和重复技术术语；
- 当宿主 Brief 选用组件不足时，只从原稿真实存在且可安全绑定的候选中补齐；
- 继续保护 H1/H2、数字、来源和事实关系，不为视觉效果制造列表、比较或结论；
- 持久安装继续注册通用 Skill、OpenCode Skill 和 `/wechat-visual-director` 命令；
- 输入协议、图片 Provider、历史任务和微信公众号草稿链路保持兼容。

## 升级

升级前先停止旧服务，再从固定 Tag 安装：

```powershell
$launcher = Join-Path $env:LOCALAPPDATA "wechat-visual-director\visual-director.ps1"
if (Test-Path $launcher) {
  powershell -ExecutionPolicy Bypass -File $launcher stop --json
}
```

随后让宿主 Agent 从以下固定版本安装或升级：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.11
```

升级不会清空安装目录中的 `data/`、`config/` 和 `runtime/`。完成后执行 `doctor --json`，确认 `persistent=true`、`version_match=true` 和 `host_skill_registered=true`。
