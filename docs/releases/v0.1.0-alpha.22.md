# v0.1.0-alpha.22

Alpha.22 把 macOS 从需要源码环境的技术预览，推进为可以直接交给 Agent 完成的自包含便携安装：Apple Silicon 与 Intel 分别获得匹配架构的 Release 包，安装、升级、启动、诊断和卸载沿用 Windows 已验证的持久化契约。普通用户无需预装 Git、Homebrew、Python、Node.js、pnpm 或 Wenyan。

## 主要变化

- 新增 macOS Apple Silicon（arm64）与 Intel（x64）自包含 `tar.gz`，内置 Python 3.11、后端依赖和生产工作台；
- 新增固定 macOS Release 安装入口：自动识别处理器架构、下载匹配资产与 `.sha256`、校验完整性并调用包内运行时安装；
- macOS 稳定入口统一为 `~/Library/Application Support/wechat-visual-director/visual-director`，程序版本位于 `versions/`，任务、图片、配置和日志保存在版本目录之外；
- 升级前会安全停止既有运行时，安装后自动启动并执行 `doctor --json`，最终返回 `workbench_url`、`settings_url`、运行时身份和首次上手说明；
- 启动、配置解析和卸载优先使用包内 Python，不再隐式依赖系统 Python；普通用户安装阶段不再依赖 `rsync`；
- 默认卸载只移除程序与宿主 Skill 注册，保留任务、图片和本机私密配置；显式 `--purge` 才完整清理；
- Release 工作流分别在 Windows x64、macOS Apple Silicon 和 macOS Intel runner 构建，并在屏蔽系统 Python 的隔离目录中完成安装、启动、诊断和卸载冒烟测试；
- 三个平台资产验收通过后，由单独发布任务一次性汇总 ZIP、tar.gz、SHA-256 和安装器，避免并行任务重复修改 Release；
- README、Skill、Agent 安装说明和官网“交给 Agent 安装”提示词统一为 Windows/macOS 双平台入口。

## 交给 Agent 安装

把本 Release 页面交给具备终端能力的 Agent，并要求它先阅读固定版本的 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/releases/tag/v0.1.0-alpha.22
```

### Windows x64

```powershell
$installer = Join-Path $env:TEMP "wechat-visual-director-install-alpha22.ps1"
Invoke-WebRequest "https://github.com/zhouke0929/wechat-visual-director/releases/download/v0.1.0-alpha.22/install-release.ps1" -OutFile $installer
$result = powershell -NoProfile -ExecutionPolicy Bypass -File $installer | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $result.launcher doctor --json
```

### macOS Apple Silicon / Intel

```bash
installer="$(mktemp -t wechat-visual-director-install.XXXXXX)"
curl -fsSL "https://raw.githubusercontent.com/zhouke0929/wechat-visual-director/main/scripts/install-release.sh" -o "$installer"
bash "$installer"
"$HOME/Library/Application Support/wechat-visual-director/visual-director" doctor --json
```

macOS 安装器会自动选择以下资产之一：

- `wechat-visual-director-macos-arm64-v0.1.0-alpha.22.tar.gz`
- `wechat-visual-director-macos-x64-v0.1.0-alpha.22.tar.gz`

安装成功应同时满足：

```text
core_ready=true
workbench_ready=true
persistent=true
version=0.1.0-alpha.22
running_version=0.1.0-alpha.22
version_match=true
runtime_match=true
runtime_mode=bundled_python
bundled_runtime=true
host_skill_registered=true
```

## 兼容性与安全

- Windows 10/11 x64 继续作为正式便携包平台；
- macOS 支持 Apple Silicon 与 Intel 自包含安装，在更多真实设备完成长期运行验证前仍标记为便携安装 Technical Preview；
- 安装与升级不会读取或回显图片 API Key、微信公众号 AppSecret、Cookie 或 Token；
- 创建公众号草稿仍需在本地工作台人工确认，项目不会自动群发；
- macOS 无法使用自包含包时仍保留源码开发路径，但普通用户和 Agent 不应默认 clone 仓库或配置开发环境。
