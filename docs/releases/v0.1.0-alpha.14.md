# v0.1.0-alpha.14

Alpha.14 修复微信公众号草稿结果不明确时的交付死角，并统一宿主 Agent 对真实 Wenyan 与 Mock 能力的判断口径。该版本仍是本地优先的开源 Alpha，不会自动群发文章。

## 主要变化

- 草稿创建成功、失败或结果未知后，冻结页始终保留“复制全文到剪贴板”和“下载交付包”；
- 复制与下载不会再次调用微信接口，`unknown` 状态下仍禁止自动重复推送；
- Wenyan Media ID 解析兼容标准文本、全角冒号、JSON 字段和带 ANSI 控制字符的输出；
- 外层命令异常退出但已经返回 Media ID 时，以真实回执为准，不再误判为结果未知；
- 超时或无法识别回执时保存退出码、输出长度与脱敏哈希，不保存原始输出、AppID 或 AppSecret；
- README、Skill 与历史产品决策明确区分：Mock 仅用于回归测试，真实草稿能力以 `doctor --json` 的运行时结果为准；
- 结果未知页面显示诊断码，便于跨电脑收集一致的问题证据。

## 兼容性与安全

- 输入 Schema、六套主题、组件库、图片 Provider 和历史任务保持兼容；
- 升级不会清空安装目录中的 `data/`、`config/` 和 `runtime/`；
- 旧任务的 `unknown` 记录不会被自动重试或自动改写；先到公众号后台核对，再使用复制或下载兜底；
- 创建公众号草稿不等于最终群发，最终审核与发布仍必须在公众号后台人工完成。

## 升级

升级前先让稳定入口执行 `stop --json`。随后从以下固定版本安装或升级：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.14
```

升级完成后执行 `doctor --json`，确认：

```text
core_ready=true
workbench_ready=true
persistent=true
version=0.1.0-alpha.14
running_version=0.1.0-alpha.14
version_match=true
```

如需真实公众号草稿，还应确认：

```text
capabilities.wechat_draft=true
publishers.wenyan.ready=true
```
