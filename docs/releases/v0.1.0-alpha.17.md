# v0.1.0-alpha.17

Alpha.17 聚焦真实运营工作台的收敛：从“双方案 + 逐组件换型”调整为“一份推荐稿 + 整篇换主题”，补齐最近五篇主题避重、封面保底与可视化裁切，并把 README 更新为与当前产品一致的安装和使用说明。

## 主要变化

- 新任务只生成一份自动选中的推荐稿，工作台支持六套完整主题即时切换与上一版回退；
- 日常工作台移除逐组件选型面板，语义组件仍由文章结构和当前主题确定性渲染；
- 最终冻结稿进入最近五篇视觉历史，优先避免连续重复主题；删除任务仍保留不含正文和图片的轻量主题摘要；
- 加强弱模型下的组件覆盖补齐、长文节奏控制和连续概念词条组识别，不为触发组件新增事实；
- 文本规划收敛为宿主 Agent + 本地规则兜底，不再要求独立 Qwen 文本模型 Key；
- 新增主题保底封面，无正文图片或生图服务时仍可完成交付；
- 封面候选支持 5:4 可视化裁切，裁切框可拖动到边缘，滑条和鼠标滚轮均可缩放；
- Seedream 提示词升级为更简洁且具场景轮换的 v6 编译策略，结构信息图继续保留锁定原文与人工确认；
- 主题样册从内部评审工具调整为面向用户的持续展示库；
- README 补齐 Wenyan 可选安装、能力分层、首次配置、公众号连接、故障排查和当前工作台截图。

## 兼容性与安全

- Windows 为正式支持平台；macOS 仍为 Technical Preview；
- 升级保留 `data/`、`config/`、图片资产和安装历史，程序目录只保留当前与上一版本；
- 基础排版不要求 Node.js、Wenyan、图片模型 Key 或微信公众号凭据；
- 图片模型 Key、AppID 和 AppSecret 仅保存在 Git 忽略的本机配置中；
- 创建微信公众号草稿必须经过工作台人工确认，最终群发仍由用户在公众号后台完成；
- 图片生成质量仍是后续迭代项，本版本不承诺所有信息图可直接发布，人工上传与 NotebookLM 等外部补图方式继续可用。

## 安装或升级

把下面的固定版本链接交给具备终端能力的 Agent，并要求其先阅读仓库根目录 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.17
```

Windows 也可以直接执行：

```powershell
$bootstrap = powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\bootstrap.ps1" | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $bootstrap.launcher doctor --json
```

升级后应确认：

```text
core_ready=true
workbench_ready=true
persistent=true
version=0.1.0-alpha.17
running_version=0.1.0-alpha.17
version_match=true
host_skill_registered=true
```
