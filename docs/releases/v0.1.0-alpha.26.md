# v0.1.0-alpha.26

Alpha.26 改善第一次安装和使用的体验：使用完整安装提示词可以一次安装并打开工作台；只把仓库链接交给 Agent 添加 Skill，也有清楚的下一步，并在首次使用时准备工作台。

## 主要变化

- Skill 开头直接提供简短上手回执：说「打开公众号工作台」或给出文章主题即可开始，同时介绍支持原生生图的宿主可以生成正文配图和封面候选。
- 轻量 Skill 内新增 Windows/macOS `ensure-workbench` 脚本；正式启动器缺失时安装校验过的 Release，已有安装只启动并检查，不重复下载、不自动升级。
- 健康检查通过后默认打开工作台；缺少可选图片或公众号凭据不阻断排版。版本、运行身份或 Skill 注册异常时，不虚报工作台就绪。
- 完整安装提示词要求返回实际工作台链接和不超过五行的教程；安装受限时说明状态和下一步，不以一句「已安装」结束。
- README、官网安装入口、Agent 安装说明、Skill 描述与 CLI 契约同步维护。

## 如何开始

完整安装可将 [Agent 安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/main/INSTALL_FOR_AGENT.md) 交给具备终端能力的 Agent，并要求安装和打开工作台。

通过仓库链接添加 Skill 后，直接说「打开公众号工作台」，或「帮我写一篇关于××的公众号文章」。正确 Skill 目录仍为 `skills/wechat-visual-director/`，不是整个源码仓库。

通用 Skill 安装器没有统一的安装后执行钩子；不同宿主是否读取安装回执由宿主决定。本版本提供前置引导与确定性准备入口，不承诺任意宿主都会在安装那一轮完成工作台安装。

## 验证与安全

- 本地 Windows 首次使用契约测试 13 项、既有安装回归 8 项通过；覆盖首次安装、重复打开、显式升级、身份校验和失败回执。
- Skill 校验与 PowerShell/Bash 语法检查通过；macOS 同等生命周期测试进入跨平台 CI。
- Windows x64、macOS Apple Silicon 与 Intel 安装包由 GitHub Actions 构建并进行自包含安装冒烟测试后发布。
- 本版本不改变文章生产规则、排版组件、数据格式和发布权限；升级保留正式数据与配置。
- 密钥只在本地设置填写，创建草稿仍由人工确认，系统不自动群发。
