# v0.1.0-alpha.12

Alpha.12 聚焦真实长文中的视觉节奏与图片可用性，不继续增加主题数量。该版本仍是本地优先的开源 Alpha，不会自动群发文章。

## 主要变化

- 长篇文章最多使用 6 个强组件，并优先覆盖不同语义形态和文章前、中、后三段；
- 支持 2–4 个连续真实术语合并为一个主题化词条组，普通正文或新 H2 会安全中断分组；
- 宿主模型只选择第一个术语时，规范化器可从同一 H2 的原文中补齐连续兄弟词条；
- 2–10 项真实核对清单可以完整绑定，不再因为只渲染前几项而丢失内容；
- 明确成对的相邻原文段落可以安全进入对比组件；
- Seedream 5.0 信息图提示升级为中央安全区、纵向阅读动线、冷白底和锁定原文；
- 正文图片候选使用 `contain` 预览，避免工作台缩略图误导性裁切；
- 复用横向正文图制作 5:4 封面时，使用柔化背景完整保留主体，不再中心裁掉两侧信息；
- Windows 启动器兼容 `pnpm.cmd`、`pnpm` 和 `pnpm.ps1`；
- Skill 文章协议、README、环境变量样例与当前多 Provider 架构同步。

## 兼容性

- 输入 Schema 继续使用 `wechat_article.v1`；
- 组件库升级为 `wechat_components.v0.12.0`；
- 渲染器升级为 `preview_renderer.v0.17.0-concept-groups`；
- 单个概念、既有任务、历史数据、图片 Provider 和微信公众号草稿链路保持兼容；
- 升级不会清空安装目录中的 `data/`、`config/` 和 `runtime/`。

## 升级

升级前先停止旧服务：

```powershell
$launcher = Join-Path $env:LOCALAPPDATA "wechat-visual-director\visual-director.ps1"
if (Test-Path $launcher) {
  powershell -ExecutionPolicy Bypass -File $launcher stop --json
}
```

随后让宿主 Agent 从以下固定版本安装或升级：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.12
```

完成后执行 `doctor --json`，确认 `persistent=true`、`version_match=true`、`host_skill_registered=true`，并重启宿主对话。
