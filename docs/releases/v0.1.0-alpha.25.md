# v0.1.0-alpha.25

Alpha.25 修复首次安装时把整份源码仓库误装成 Skill、却没有安装本地工作台的问题。轻量 Skill 与完整产品安装现在拥有清晰的物理边界；普通用户只需把统一安装说明链接交给 Agent，即可在同一轮完成正式 Release、Skill 注册、健康检查和工作台打开。

## 主要变化

- 将可分发 Skill 从仓库根目录迁移到独立的 `skills/wechat-visual-director/`，只保留入口、UI 元数据与必要协议文件；
- 仓库根不再放置 `SKILL.md`，防止通用 Skill 安装器把 `apps/`、`docs/`、`.github/` 等开发源码整体复制到宿主 Skill 目录；
- Windows 与 macOS 正式安装器同时注册 Codex、通用 Agent 和 OpenCode Skill，并在升级时完整替换旧注册目录，自动清除历史整仓快照；
- 面向普通用户的推荐入口统一为 `INSTALL_FOR_AGENT.md`，明确要求同一轮安装轻量 Skill 与本地工作台、运行 `doctor --json` 并打开工作台；
- Windows Agent 安装入口可从主分支 `VERSION` 自动解析当前公开版本，不再要求安装提示词绑定某个 Alpha 版本；
- `doctor` 新增 Codex Skill 注册检查，完整卸载同步清理三个宿主目录；Windows `-Purge` 也会清理历史备份目录；
- 安装回归新增轻量 Skill 文件白名单：任何注册目录都不得包含 `apps/`、`docs/` 或 `.github/`。

## 交给 Agent 安装

把下面这一条统一安装说明链接交给具备终端能力的 Agent：

```text
https://github.com/zhouke0929/wechat-visual-director/blob/main/INSTALL_FOR_AGENT.md
```

Agent 必须同时完成正式工作台和轻量 Skill 的安装。直接把 Skill-only 子目录交给通用 Skill 安装器只适合明确需要协议文件的高级用户，不代表工作台已经安装。

### Windows x64

```powershell
$installer = Join-Path $env:TEMP "wechat-visual-director-install.ps1"
Invoke-WebRequest "https://raw.githubusercontent.com/zhouke0929/wechat-visual-director/main/scripts/install-release.ps1" -OutFile $installer
$result = powershell -NoProfile -ExecutionPolicy Bypass -File $installer | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $result.launcher doctor --json
```

### macOS Apple Silicon / Intel

```bash
installer="$(mktemp -t wechat-visual-director-install.XXXXXX)"
curl -fsSL "https://raw.githubusercontent.com/zhouke0929/wechat-visual-director/main/scripts/install-release.sh" -o "$installer"
bash "$installer"
"$HOME/Library/Application Support/wechat-visual-director/visual-director" doctor --json
```

## 兼容性与安全

- Windows 10/11 x64 与 macOS Apple Silicon / Intel 继续使用自包含便携包，不要求用户预装 Git、Python、Node.js、pnpm、Homebrew 或 Wenyan；
- 升级保留正式任务、图片和本机私密配置，只替换程序版本与宿主 Skill 注册；
- Agent 不得读取或回显 API Key、AppSecret、Cookie 或 Token；
- 创建公众号草稿仍需用户在工作台明确确认，最终群发继续由人工完成。
