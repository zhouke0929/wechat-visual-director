# v0.1.0-alpha.27

Alpha.27 优化安装后的引导与工作台首页：内容交给 Agent 整理和规划，工作台专注编辑、审核和交付。

## 主要变化

- 首页提供「我有一个选题 / 我有一篇文章」两种 Agent 指令，撤下手动 Markdown 上传、内容类型选择和示例导入。已有原稿也先由 Agent 保留事实、整理结构并完成语义规划。
- 简要指南直接融入首页三步流程，说明宿主生图、零 Key 排版及人工交付边界；无需点击「我已了解」。适度放大文字，常见桌面尺寸下完整一屏展示。
- 最近任务迁至独立页面，顶部及「继续已有任务」都可进入；页头与主题样本册、本地设置统一，保留分页、管理与任务返回路径。
- 复制指令后仅在原按钮显示短暂的「已复制」，不插入新提示行、不推动页面；复制受限时选中文本供手动复制。
- 安装说明明确通用 Skill 安装器复制文件后应继续准备工作台；检查回执提供简短教程。普通再次打开不重复完整教程，不代用户确认已读。
- README、Skill、安装指南、CLI 契约及浏览器回归脚本同步更新。

## 如何测试

将 [仓库链接](https://github.com/zhouke0929/wechat-visual-director) 交给 Agent 并要求安装，或使用 [完整安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/main/INSTALL_FOR_AGENT.md)。进入工作台后，首页右上角应显示 `0.1.0-alpha.27`。

不同宿主的通用 Skill 安装器没有统一的安装后执行钩子；项目无法强制未读取说明的宿主在同一轮完成全部步骤。若宿主只添加了 Skill，可直接说「打开公众号工作台」继续准备。

## 验证与边界

- TypeScript 与生产构建、Skill 校验，以及浏览器端首页布局、复制反馈、任务分页和模拟管理回归通过。
- 桌面 1280×720、1366×768、1440×900、1920×1080 一屏展示，390px 窄屏无横向溢出；首页不读取或写入已读状态。
- Windows x64、macOS Apple Silicon 与 Intel 安装包由 GitHub Actions 构建并通过自包含安装冒烟测试后发布。
- 不改变文章生产组件数量限制、语义规划规则或微信交付权限。底层任务创建 API/CLI 继续供 Agent 使用，规则兜底保留为内部容错。
- 图片及微信密钥仍由用户在本地设置填写；真实生图和创建公众号草稿仍遵循人工确认，不自动群发。
