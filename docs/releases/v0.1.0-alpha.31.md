# v0.1.0-alpha.31

这是 alpha.30 的累积更新，集中完善独立安装、自定义主题创作引导、任务继续与生图入口。已有任务、图片和本地配置继续保留，无需先安装中间版本。

## 安装与主题加载更可靠

- 安装默认使用自身的数据目录。发现独立开发环境的数据时提供可选迁移提示，拒绝迁移不会阻断独立安装；不自动选择任务最多的数据库。
- 主题安装通过正式渲染与交付检查后才启用。异常扩展主题单独显示诊断，其它正常主题和样本册仍可使用。

## 自定义主题创作更完整

- Skill 按安装、文章、主题、配图和交付等任务选择相关说明，减少无关上下文，同时保留参考研究、关联元素联想、全组件扩展和重点视觉修订。
- 视觉评审区分阅读、主题表现与整篇取舍，既检查排版缺陷，也检查正文重点的构图表现。不以装饰数量、异形数量或程序通过代替美观判断。
- README、网站、安装回执和工作台统一推荐提供喜欢的组件截图创作整套主题；纯描述仍可探索方向，但输出质量可能需要继续确认。

## 更容易继续已有工作

- 最近任务支持按标题关键词搜索，包含完整历史分页，不只过滤当前页。
- Agent 可通过只读 `task list --query` 查找标题、状态、更新时间与任务入口，用户无需自行查找任务 ID。
- 配图与封面区域增加可复制的 Agent 指令，自动带上当前任务链接。若当前对话支持原生生图，可直接生成待审核候选，无需配置工作台图片 API；图片仍由用户审核采用。
- “回到上一版”补充样式恢复范围说明。沿用已有连续回退能力，保留当前正文和图片，不更改公众号后台已有草稿。
- README 与在线介绍按“排好文章 / 创作主题”组织使用入口，并补齐图文复制的说明：既有复制能力可携带正文图片与主题装饰，无需微信 API；封面、标题等发布信息仍需在后台设置。该项是说明更新，不是新增复制实现。

## 评测与验证边界

- 开发评测固定需求、原稿、参考和 Skill 快照，分别记录工程、视觉和微信保存后结果；评测材料不进入用户安装包。
- 本轮出游手帐主题由新会话独立完成，原版本通过本地独立审计；用户确认同版本全组件验收稿的 API 与复制保存、重开和手机预览均正常。复制时仍有未明细警告，未观察到格式错误。
- 两个纯描述用例的视觉不足保留记录。这些小样本不代表通用成功率，不保证所有主题、所有设备或深色模式均已验证。
- 不自动使用收费生图服务，不读取或迁移其它安装的私密配置，不自动群发。

安装与升级入口见 [安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/main/INSTALL_FOR_AGENT.md)。发布流程对 Windows x64、macOS Apple Silicon 与 Intel 安装包分别构建并执行安装检查。
