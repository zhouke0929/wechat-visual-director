# v0.1.0-alpha.21

Alpha.21 聚焦“更轻的图片配置、更可靠的审核交互和更清楚的首次上手”：图片模型收敛为统一入口，候选生成与审核状态进一步简化；封面从破坏性裁切改为保留原图的可调整显示区；首次安装完成后，Agent 会用极短回执告诉用户下一步可以做什么。

## 主要变化

- 图片模型配置收敛为统一入口：填写完整 Endpoint、Model ID、API Key 与清晰度，OpenAI Images、Seedream、Nano Banana 等厂商差异由隐藏 Adapter 处理；
- 改进第三方图片接口兼容和错误诊断，区分 HTTP 成功、业务失败、无效图片与可下载图片 URL；
- 正文图片候选不再限制为三张，用户可以持续生成并保留旧候选；多个图片槽可以分别发起生成请求；
- 移除工作台顶部一键批量配图与确定性保底信息图，保留单张生成、继续抽卡、人工上传和跳过；
- 宿主 Agent 原生生图返回不再因中途换主题而直接丢弃，图片会进入工作台成为待审核候选并展示当前主题协调度；
- AI 封面 OCR 只保留内部诊断，不再用不确定的自动识别结果制造红色警告或阻断采用；
- 封面保留 1080×864（5:4）候选母图，通过可移动的 900×383（约 2.35:1）“封面显示区”决定公众号头图内容；保存时不覆盖、裁掉或复制原图；
- “完整宽度”取代容易误解的“100%”，候选卡片与编辑器使用同一显示参数；
- 首次安装结果新增 `first_install` 与 `first_run_guide`，Agent 只在首次安装后返回不超过五行的上手说明，并提示具备原生生图能力时可在确认主题后直接生成和插入配图；
- README、Skill、图片 Provider 说明、官网复制安装提示词和产品决策记录同步更新。

## Windows 安装

把本 Release 页面交给具备终端能力的 Agent，并要求它先阅读固定版本的 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/releases/tag/v0.1.0-alpha.21
```

或在 PowerShell 执行：

```powershell
$installer = Join-Path $env:TEMP "wechat-visual-director-install-alpha21.ps1"
Invoke-WebRequest "https://github.com/zhouke0929/wechat-visual-director/releases/download/v0.1.0-alpha.21/install-release.ps1" -OutFile $installer
$result = powershell -NoProfile -ExecutionPolicy Bypass -File $installer | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $result.launcher doctor --json
```

安装成功应同时满足：

```text
core_ready=true
workbench_ready=true
persistent=true
version=0.1.0-alpha.21
running_version=0.1.0-alpha.21
version_match=true
runtime_match=true
runtime_mode=bundled_python
bundled_runtime=true
host_skill_registered=true
```

## 兼容性与安全

- Windows 10/11 x64 为正式便携包平台；macOS 继续作为源码安装 Technical Preview；
- 升级保留 `data/`、`config/`、图片资产、历史任务和本机凭据；
- 首次使用说明只在新安装后展示，升级、修复或换对话不会重复打扰；
- 图片 API Key、微信公众号 AppSecret 与 Cookie 只在本机设置页填写，不进入对话或发行资产；
- 创建公众号草稿仍需工作台人工确认，项目不会自动群发。
