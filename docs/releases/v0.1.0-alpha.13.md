# v0.1.0-alpha.13

Alpha.13 聚焦 OpenCode、WorkBuddy、Trae 等 Windows 桌面 Agent 的稳定启动与故障可解释性。该版本仍是本地优先的开源 Alpha，不会自动群发文章。

## 主要变化

- 修复 `pnpm.cmd` 位于带空格目录时被 `cmd.exe` 错误拆分的问题；
- 安装结果新增 `launcher_cmd`，为偏好 CMD 的桌面 Agent 提供稳定入口；
- 工作台新增独立身份与版本端点，CLI 不再把任意返回 200 的网页误判为当前工作台；
- 端口被旧版或其他项目占用时返回 `workbench_version_mismatch`，不再静默复用错误页面；
- API 启动后再次校验应用版本与设置契约，避免系统 Python 启动旧核心；
- 任务页先加载文章和双方案，再后台补载图片、封面与发布状态；单个附属接口失败不会让页面永久停在“正在装订”；
- 前端首屏请求加入超时与核心版本检查，任务页渲染异常会显示可重试错误页；
- Skill 明确禁止宿主在稳定入口失败后改用全局 uvicorn 或临时源码目录手动兜底。

## 兼容性

- 输入 Schema、六套主题、组件库、图片 Provider、历史任务与微信公众号草稿链路保持兼容；
- 升级不会清空安装目录中的 `data/`、`config/` 和 `runtime/`；
- PowerShell 入口继续保留，`launcher_cmd` 是新增的等价入口。

## 升级

升级前先使用原稳定入口执行 `stop --json`。随后从以下固定版本安装或升级：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.13
```

升级完成后执行 `doctor --json`，确认 `core_ready=true`、`workbench_ready=true`、`persistent=true` 与 `version_match=true`。若返回版本不匹配错误，关闭占用 8000 或 3000 端口的旧进程后，只从稳定入口重试。
