# v0.1.0-alpha.33

本次为工作台交互补丁，优化正文配图与封面的 Agent 生图指令入口；不改变文章渲染、生图能力或数据存储方式。

## 更轻量的 Agent 配图入口

- 移除配图审核与封面区域内的大边框说明卡，改为标题旁的「让 Agent 配图」或「让 Agent 生成」文字入口，减少对图片审核的干扰。
- 点击后直接展示完整、分段的任务指令，增大字号和阅读区域；去掉重复步骤介绍与折叠操作，打开即可查看并复制。
- 保留正文配图与封面的任务绑定。指令只请求生成待审核候选，不覆盖已采用图片，不自动采用图片或创建公众号草稿。
- 复制失败时自动选中指令供手动复制；弹窗支持 Esc、关闭按钮与遮罩关闭，并将焦点还给原入口。

## 使用与升级

这个入口用于复制指令后发回 Agent 对话，不会在工作台内直接调用模型。Agent 需具备可调用的生图工具；没有时仍可使用自己的图片。生成后刷新工作台，审核并决定是否采用。

安装器按 `main/VERSION` 获取已发布安装包；已有安装请明确执行升级，单独刷新网页不会升级程序。正常升级沿用现有文章、图片、自定义主题和配置，本次不新增数据迁移。

验证覆盖前端类型检查与构建、任务绑定与复制成功/失败、弹窗关闭和焦点恢复、桌面与窄屏展示；发布流水线继续执行跨平台测试和真实安装包验证。Windows x64、macOS Apple Silicon 与 Intel 提供安装包及 SHA-256，macOS 仍为 Technical Preview。
