# v0.1.0-alpha.18

Alpha.18 聚焦图片系统与长周期运营体验：将信息图、氛围图和 AI 封面统一到可扩展的文章级 Visual DNA，补齐主题切换后的候选保留与兼容提示、图片加载恢复，以及历史任务服务端分页。本版本继续保持“一份推荐稿 + 人工确认 + 草稿交付”的主流程。

## 主要变化

- 新增 `image_visual_intent.v3`，把图片目的、信息关系、场景隐喻、空间区域、节点视觉和连接语言拆成供应商无关的视觉脚本；
- 结构信息图采用“完整事实锚点 + 原文短标签”双层契约，长正文不再强迫模型整段排字，OCR 只核对实际要求绘制的文字；
- 一篇文章只解析一份图片美术方向，正文信息图、氛围图与 AI 封面共享画材、色板、表面语言和视觉气质；
- 主题与图片风格从成对兼容矩阵升级为 Visual DNA 评分，新主题或新图片风格只需注册自己的 Manifest；
- 换主题继续保留已生成、已采用和人工上传的图片，明显冲突只做轻提示，默认不重生图片、不增加费用；
- 未来科技新增 `editorial_tech_collage`：使用科技编辑拼贴、半透明信息薄片和连续信号曲线，禁止路牌、深色道路和玩具微缩模型；
- AI 封面直接复用全文 EditorialBrief 与文章 Visual DNA，使用 5:4 单焦点底图，不生成标题、步骤卡或多面板；
- 图片缩略图和文章预览增加自动重试、原位手动重载与最新请求令牌，快速切换主题时旧响应不再覆盖当前状态；
- 历史任务改为服务端分页，首页默认每页 8 篇；批量选择只作用于当前页，删除最后一项后自动回到有效页；
- README 更新图片生成逻辑、当前工作台截图、固定版本安装链接和本版本说明。

## 兼容性与安全

- Windows 为正式支持平台；macOS 仍为 Technical Preview；
- 升级保留 `data/`、`config/`、图片资产和本机凭据，程序目录只保留当前与上一版本；
- 无参数的历史任务列表仍返回旧版结构，分页参数是向后兼容的新能力；
- 图片生成和主题切换不绕过人工确认，也不会自动调用模型产生额外费用；
- 图片短标签必须是事实锚点的连续原文子串，视觉隐喻不得新增院校、政策、数字或官方背书；
- 创建微信公众号草稿仍需 Wenyan、本机凭据与人工门禁，最终群发仍由用户在公众号后台完成。

## 安装或升级

把下面的固定版本链接交给具备终端能力的 Agent，并要求其先阅读仓库根目录 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.18
```

Windows 也可以直接执行：

```powershell
$bootstrap = powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\bootstrap.ps1" | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $bootstrap.launcher doctor --json
```

升级后应确认：

```text
core_ready=true
workbench_ready=true
persistent=true
version=0.1.0-alpha.18
running_version=0.1.0-alpha.18
version_match=true
host_skill_registered=true
```
