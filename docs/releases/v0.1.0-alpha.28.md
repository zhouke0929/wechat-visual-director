# v0.1.0-alpha.28

Alpha.28 完善参考图驱动的自定义主题创作，让 Agent 从参考与联想出发完成整套主题，并统一工作台、离线检查与交付验收的尺度。

## 主要变化

- 根据风格描述或组件参考图，先寻找互补参考、延展关联元素，再设计正文承载方式和完整组件家族；默认完成全部 21 类布局，不把少量试样当成整套主题交付。
- 评审同时关注阅读可用性与关键构图表现力，保留有代表性的招牌造型，按阅读任务调整强弱与复用，不机械追求去矩形或增加装饰。
- 新增离线 `theme review` 和可选浏览器检查工具，覆盖真实图片、长短文案、局部修订及正常文章。手机视口统一为 405px，校对视口为 648px；正文净宽分别为 357px、600px。
- 受控 PNG 图案支持多边形和全宽载体；原文已有标题编号时不再重复添加徽章编号。普通引用与证据强调按语义区分。
- 交付检查区分微信结构警告和实际缺陷，按主题版本、样张及 API/复制路径记录保存、重开和手机结果，不自动继承其它主题的验证状态。
- Windows 构建保留证书校验并提供备用下载传输；两平台构建清理整个发行载荷的编译缓存。历史测试稿、内部截图与临时文档不进入本次提交。

## 如何使用

把 [仓库链接](https://github.com/zhouke0929/wechat-visual-director) 交给 Agent，并按 [安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/main/INSTALL_FOR_AGENT.md) 安装或升级。可以说：“参考这张组件截图，帮我制作一套新的公众号主题，并展示完整文章效果。”

## 验证与边界

- 本地后端全量 484 项通过、1 项 Windows 不适用的 POSIX 测试跳过；前端生产构建与 Skill 校验通过。
- Windows 自包含候选包的隔离安装、启动、健康检查、任务创建及包内离线主题检查通过。Windows x64、macOS Apple Silicon/Intel 的正式资产由 Actions 构建并完成安装检查后发布。
- 用户实测“散场手记”1.2.0 的全部 21 类组件、正文图片与小图案：API、复制图文两条路径均保存、重开及手机预览正常。微信仍有渐变和零行高提示；结论只覆盖已测主题和环境，深色模式未单独验证，不代表所有新主题已获兼容认证。
- 极深 Windows 安装路径仍可能受到原生 DLL 路径长度限制；此次安装检查使用隔离的短路径，不承诺任意路径均可用。
- 不改变正常文章的组件数量限制，不修改原文事实，不自动重生成已确认图片。密钥仍在本机填写，创建草稿需人工确认，最终群发始终由人工完成。
