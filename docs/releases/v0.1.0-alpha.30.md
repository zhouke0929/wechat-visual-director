# v0.1.0-alpha.30

这是 alpha.29 的累积更新，完善主题样本册、参考驱动主题创作的发现入口和正式渲染链路校验。保留已有主题创作、图文复制及升级数据保护能力，不需要先安装旧版本。

## 完整样本册与导读设计

- 工作台与在线展示统一提供 14 项基础样式和 12 类语义组件，共 26 项部件；导读、普通引用、列表、图片说明、表格及文章末尾等不再遗漏。
- 整篇样张与基础部件通过实际文章渲染入口生成，避免样本册展示与正式文章使用不同样式。预览沿用工作台的手机内容宽度和正文内边距。
- 为新中式雅集、复古报刊、波普海报、自然图鉴、商业画报、电影叙事补齐各自的导读设计，不再共用单一浅绿色色块。真实文章仍只在原文有导读时使用，不额外编造导读。

## 用户更容易发现和使用新主题创作

- README、在线网站及工作台首页加入参考组件截图或风格描述创作整套新主题的说明和可复制指令。
- 安装完成仍只返回四行简要教程，同时说明新主题创作和宿主 Agent 原生生图候选能力；不要求先配置图片或公众号凭据才能开始排版。
- 自定义主题交付校验加入正式渲染入口探测：分别检查短、长内容，避免布局在独立样本中可渲染、实际文章却被忽略。检查失败时返回诊断，不报告交付成功。
- 原封不动沿用模板的布局会提示视觉评审，但不会把改色或程序通过判定为美观，也不自动否定刻意简约的设计。

## 验证与边界

- 发布前执行后端回归、前端构建、静态展示同步检查及公开样本浏览器检查。三平台正式安装包由 Actions 构建，并通过首次安装和非空数据保留检查后发布。
- 本机干净环境后端回归：498 项通过、15 项按环境条件跳过，0 失败。公开样本浏览器检查覆盖桌面与 405px 手机视口、完整部件导航和指令复制兜底。
- 本地展示、渲染链路和图片加载检查不等于微信公众号保存后实测认证；新增导读样式的微信最终展示仍需使用者预览确认。
- 不自动迁移来源不明的数据，不修改用户文章事实，不自动群发。测试样本、私密配置及本机数据库不进入仓库或安装包。
