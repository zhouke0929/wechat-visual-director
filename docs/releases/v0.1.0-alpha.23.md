# v0.1.0-alpha.23

Alpha.23 完善了宿主 Agent 原生生图与本地工作台之间的候选交接：正文图片已经采用、替换或积累多个候选后仍可继续生成；封面获得同等的受控请求与回传通道。所有新图片只会追加为待审核候选，不覆盖用户当前选择。

## 主要变化

- 正文图片槽不再因为已经采用、替换或存在历史候选而停止下发宿主生图请求；
- 正文与封面候选均取消历史数量上限，允许用户按需持续生成和比较；
- 新增封面宿主请求：支持单独读取封面或一次读取正文与封面的主题绑定 Prompt；
- 新增封面专用 `host-import`，保存请求 ID、宿主名称、模型、Prompt 哈希和生成时方案 revision；
- 正文和封面导入都只追加待审核候选，保持当前采用结果不变，不替用户自动选择；
- 生成期间仅切换主题不会拒绝正文或封面回传；真正的文章语义、图片任务或候选 revision 变化才要求重新读取请求；
- 空请求改为明确的 `host_image_handoff_blocked`，并返回逐目标阻断原因；Skill 要求 Agent 硬停止，不得自行补写 Prompt 或伪装成人工上传；
- CLI 增加 `image context --asset-type body_image|cover|all` 和封面导入参数；
- 工作台能区分“宿主原生生图”封面来源；README、Skill 与 CLI 契约同步更新。

## 交给 Agent 安装

把本 Release 页面交给具备终端能力的 Agent，并要求它先阅读固定版本的 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/releases/tag/v0.1.0-alpha.23
```

### Windows x64

```powershell
$installer = Join-Path $env:TEMP "wechat-visual-director-install-alpha23.ps1"
Invoke-WebRequest "https://github.com/zhouke0929/wechat-visual-director/releases/download/v0.1.0-alpha.23/install-release.ps1" -OutFile $installer
$result = powershell -NoProfile -ExecutionPolicy Bypass -File $installer | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $result.launcher doctor --json
```

### macOS Apple Silicon / Intel

```bash
installer="$(mktemp -t wechat-visual-director-install.XXXXXX)"
curl -fsSL "https://raw.githubusercontent.com/zhouke0929/wechat-visual-director/main/scripts/install-release.sh" -o "$installer"
bash "$installer"
"$HOME/Library/Application Support/wechat-visual-director/visual-director" doctor --json
```

macOS 安装器会自动识别处理器架构并选择 `arm64` 或 `x64` 的自包含 Release 包。

## 兼容性与安全

- Windows 10/11 x64 与 macOS Apple Silicon / Intel 继续使用自包含安装包，不要求用户预装 Python、Node.js 或 Git；
- 升级保留正式任务、图片、公众号配置和图片 Provider 私密配置；
- 宿主通道不会读取工作台保存的图片 API Key，也不会静默降级到收费图片 API；
- 新候选必须在本地工作台人工审核和采用，创建公众号草稿仍需用户明确确认。

## 验证

- API 与 CLI 测试覆盖已采用正文槽继续追加、空请求阻断、封面请求与回传、并发 revision 冲突和主题切换兼容；
- Web 类型检查、生产构建和宿主封面来源展示通过；
- Windows 与 macOS Release 继续在 GitHub Actions 中构建自包含资产并执行隔离安装冒烟测试。
