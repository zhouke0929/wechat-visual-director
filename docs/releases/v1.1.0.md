## 这次更新

- **由 Agent 完成首轮排版。** 工作台接收 Agent 按原稿整理的方案，供用户编辑、换主题和交付。原稿明确要保留为正文的段落不再被补成组件；局部规划问题不会一并覆盖其他有效选择。
- **推荐信息图支持 2–5 个节点。** 由首轮排版的 Agent 根据原文判断是否适合，并给出图中文字；不是遇到五个步骤就自动配图。
- **26 套主题共用组件渲染接口。** 主题保留各自的装饰，逻辑路径的编号、标题和说明层次更清楚；理性网格减少多余留白，青春校园的引用标签在手机上更紧凑。
- **工作台编辑更稳。** 修复快速离开正文输入区时保存提示滞留、页面跳动，以及切换手机预览时未保存修改可能丢失的问题。
- **表格换主题不丢列。** 修复部分主题只展示前四列、空单元格错位，以及理性网格表格粘贴进微信后底部细线变成色块的问题。
- **官网展示页重新编排。** 通过四个章节了解产品，并可在手机样稿中切换主题查看排版效果。

## 安装与升级

将[安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/v1.1.0/INSTALL_FOR_AGENT.md)交给 Agent；已安装的用户请明确要求升级到 `v1.1.0`。Windows 提供 x64 安装包；macOS 提供 Apple Silicon 和 Intel 两种自包含安装包，仍为 Technical Preview。各安装包均附 SHA-256 校验文件。
