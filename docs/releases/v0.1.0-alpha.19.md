# v0.1.0-alpha.19

Alpha.19 聚焦“真实交付可靠性、跨 Agent 安装体验与主题扩展”：内置微信公众号草稿发布器，移除 Wenyan 与 Node.js 运行依赖；将服务改为隐藏后台进程，并补齐运行时身份校验、失败恢复、发布结果未知时的人工解锁，以及 12 套主题和可扩展 Visual DNA。

## 主要变化

- 内置微信公众号官方 API 发布器，直接完成 access token 获取、正文图片上传、封面素材上传与草稿创建；正常使用不再安装或调用 Wenyan；
- AppID 与 AppSecret 只保存在本机私有配置中，access token 仅驻留内存；白名单状态改为真实连通性探测，不再依赖用户手动勾选；
- 发布结果未知时提供“后台已找到草稿”和“后台未找到、允许重试”两条恢复路径，不再把任务永久锁死；复制富文本与下载交付包仍可作为兜底；
- 正常安装直接使用仓库内置的生产工作台，不需要 npm、pnpm 或 `pnpm dev`；Node.js 仅用于开发与 CI 构建；
- Windows 服务改为隐藏后台进程，启动命令可及时返回；日志写入持久目录并轮转，工作台不再弹出空终端窗口；
- 新增运行时身份、版本、数据根与前端指纹校验，防止旧服务、临时源码和正式数据目录交叉；
- 主题扩展到 12 套，引入主题贴纸资产、非矩形结构和主题专属组件语言，降低“只换色”的相似感；
- Visual DNA、图片意图与主题注册逻辑继续解耦，新主题通过 Manifest 参与配图风格评分，无需维护成对硬编码矩阵；
- 优化语义组件识别、组件密度、标题与来源层级，修复“可靠来源”被误判为行动清单、编号进入图片标题以及微信端边距等问题；
- 简化工作台顶部信息，发布按钮直接说明唯一阻断原因；封面支持跳过、拖拽裁剪、滚轮缩放与人工上传；
- 历史任务支持分页、批量删除与明确的数据清理语义。

## 兼容性与安全

- Windows 为正式支持平台；macOS 当前仍为 Technical Preview；
- 升级默认保留 `data/`、`config/`、图片资产和本机公众号凭据；卸载默认不删除业务数据；
- 正常安装不访问 npm，不会修改用户的 Node.js 环境；
- 公众号草稿创建始终需要本机 AppID、AppSecret 与开发者后台 IP 白名单；项目不会自动群发文章；
- “结果未知”只代表客户端无法确认服务端结果，必须由用户核对公众号后台后再选择恢复路径，避免重复草稿；
- API Key、AppSecret、Cookie、数据库与本地测试稿均不进入发行版本。

## 安装或升级

把下面的固定版本链接交给具备终端能力的 Agent，并要求其先阅读仓库根目录 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.19
```

Windows 也可以直接执行：

```powershell
$bootstrap = powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\bootstrap.ps1" | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $bootstrap.launcher doctor --json
```

升级后应确认：

```text
core_ready=true
workbench_ready=true
persistent=true
version=0.1.0-alpha.19
running_version=0.1.0-alpha.19
version_match=true
runtime_match=true
host_skill_registered=true
```
