# v0.1.0-alpha.24

Alpha.24 把“内容校对”升级为受控的原文原位编辑器：运营可以在接近微信公众号后台的桌面画布中直接修改标题、正文和组件文案，修改自动保存并同步到手机预览；主题结构、装饰、图片位置和发布边界继续由确定性核心保护。

## 主要变化

- 内容校对采用 600px 正文净宽，手机预览采用 405px 逻辑视口，分别对齐本轮公众号后台与实机验收基准；
- 支持在原文位置编辑标题、段落、小标题、引用、来源、列表项和表格单元格，不再弹出二级编辑窗口；
- 内容修改使用独立 revision、自动保存和冲突保护，离开编辑位置后应用服务端重渲染，并保留当前阅读位置；
- 内容校对与手机预览读取同一工作版本；修改结构信息图引用的文字时同步更新事实锚点；
- 冻结时校验最新内容 revision，并移除所有工作台编辑标记，复制、导出和公众号草稿继续使用干净的不可变 HTML；
- 十二套主题统一识别固定标签后的裸正文、行内强调和复杂组件文案，编辑框只覆盖真实正文，不开放编号、标签与装饰；
- 编辑悬停和聚焦统一为半透明淡绿反馈，兼容白底、纸色和彩色主题背景；
- 修复点击空白自动保存后预览跳回顶部、手机滚动条伸入底部操作区，以及无空格长文本撑出横向滚动条的问题；
- 主题扩展新增编辑覆盖状态，便于后续扩展包自动发现漏映射文本。

## 交给 Agent 安装

把本 Release 页面交给具备终端能力的 Agent，并要求它先阅读固定版本的 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/releases/tag/v0.1.0-alpha.24
```

### Windows x64

```powershell
$installer = Join-Path $env:TEMP "wechat-visual-director-install-alpha24.ps1"
Invoke-WebRequest "https://github.com/zhouke0929/wechat-visual-director/releases/download/v0.1.0-alpha.24/install-release.ps1" -OutFile $installer
$result = powershell -NoProfile -ExecutionPolicy Bypass -File $installer | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $result.launcher doctor --json
```

### macOS Apple Silicon / Intel

```bash
installer="$(mktemp -t wechat-visual-director-install.XXXXXX)"
curl -fsSL "https://raw.githubusercontent.com/zhouke0929/wechat-visual-director/main/scripts/install-release.sh" -o "$installer"
bash "$installer"
"$HOME/Library/Application Support/wechat-visual-director/visual-director" doctor --json
```

macOS 安装器会自动识别处理器架构并选择 `arm64` 或 `x64` 的自包含 Release 包。

## 兼容性与安全

- Windows 10/11 x64 与 macOS Apple Silicon / Intel 继续使用自包含安装包，不要求用户预装 Python、Node.js 或 Git；
- 升级保留正式任务、图片、公众号配置、图片 Provider 私密配置和既有冻结版本；
- 浏览器只提交稳定内容块的文字值，不把自由修改后的组件 DOM 作为发布来源；
- 创建公众号草稿仍需用户在工作台明确确认，最终群发继续由人工完成。

## 验证

- API 回归覆盖内容 revision、类型与结构校验、方案重渲染、冻结并发和编辑标记清理；
- Web 类型检查与生产构建通过；
- 浏览器回归覆盖原位编辑、自动保存、滚动位置保持、双预览同步、十二主题文本映射和手机横向溢出；
- Windows 与 macOS Release 继续由 GitHub Actions 构建自包含资产并执行隔离安装冒烟测试。
