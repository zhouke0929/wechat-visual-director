# v0.1.0-alpha.15

Alpha.15 聚焦首次安装、换新对话、能力配置和桌面 Agent 兼容性。它把此前需要开发者协助的安装与设置步骤收敛成稳定入口，同时保留本地优先、人工审核和不自动群发的安全边界。

## 主要变化

- 新增统一 `bootstrap.ps1`：安装或升级、启动服务、执行健康检查，并只在 stdout 返回结构化结果；
- 新增安全 `uninstall.ps1`：默认保留任务与私有配置，显式 `-Purge` 才彻底删除；
- 新增面向 Agent 的唯一安装说明 `INSTALL_FOR_AGENT.md`，新对话先检查稳定入口，不再重复安装；
- Skill 触发描述覆盖公众号写作、排版、视觉评审与草稿交付，新会话无需记住旧对话上下文；
- `/settings` 支持“仅排版”“排版 + 生图”“完整交付”三种目标，按需显示图片与微信公众号配置；
- AppID、AppSecret 只由用户在本机设置页填写，API 与页面不会回显原值；
- 公网出口 IP 改为用户主动检测，并提供明显的复制成功反馈；
- Next.js 工作台改用生产构建和同源运行时代理，不再依赖固定端口 CORS 或 `pnpm dev`；
- 安装只保留当前和上一程序版本，业务数据、图片、配置与日志位于版本目录之外；
- Windows 启动器记录真实监听进程，停止、重启和端口恢复不再依赖易失的父进程 PID。

## 兼容性与安全

- 输入 Schema、六套主题、组件库、图片 Provider、Wenyan 交付和历史任务保持兼容；
- 升级不会清空安装目录中的 `data/`、`config/` 或 `runtime/`；
- 基础排版不要求图片 Key 或微信公众号凭据；
- Mock 仍只用于回归和演示，真实草稿能力以 `doctor --json` 的运行时结果为准；
- 创建草稿不等于最终群发，最终审核与发布必须在微信公众号后台完成。

## 安装或升级

把下面的固定版本链接交给具备终端能力的 Agent，并要求其先阅读仓库根目录 `INSTALL_FOR_AGENT.md`：

```text
https://github.com/zhouke0929/wechat-visual-director/tree/v0.1.0-alpha.15
```

Windows 也可以直接执行：

```powershell
$bootstrap = powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\bootstrap.ps1" | ConvertFrom-Json
powershell -NoProfile -ExecutionPolicy Bypass -File $bootstrap.launcher doctor --json
```

升级后应确认：

```text
core_ready=true
workbench_ready=true
persistent=true
version=0.1.0-alpha.15
running_version=0.1.0-alpha.15
version_match=true
host_skill_registered=true
```
