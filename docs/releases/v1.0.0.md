公众号视觉主编是开源的公众号排版 Skill 与本地工作台。Windows x64 提供稳定版；macOS Apple Silicon 和 Intel 提供自包含安装包，仍为 Technical Preview。

## 这次更新

- **26 套官方主题。** 样本册可按风格浏览，工作台点主题卡即可在自己的文章上换版，保留正文、图片和撤回能力。新增像素插画生图风格，优化散场手记与黑白墨迹的配图方向。
- **参考组件图可以扩展成整套主题。** 保留参考的代表性构图，将风格延伸到标题、列表、图文和重点组件，再用完整文章和样本册验收。
- **编辑页直接复制图文。** 不用先选封面、冻结或者配置微信 API；原稿图片、已采用的配图和主题装饰随正文复制。标题和封面在公众号后台设置。
- **交付检查更明确。** 保存前提示未完成的配图、封面等操作；等最新正文保存后再生成最终稿。修复正常图文被 HTML 检查误拦的问题。创建微信草稿结果不明确时，先核对草稿箱，不自动重试。
- **本地设置与升级更清楚。** 不接图片 API 也能排版、上传图片或使用支持生图的 Agent；工作台不会用占位图冒充生成候选。升级保留原有文章、图片、自定义主题与本地配置。
- **官网支持在线换主题。** 26 套主题都可以在手机预览内切换并阅读完整样稿，无需安装。

## 安装与升级

把 [安装说明](https://github.com/zhouke0929/wechat-visual-director/blob/v1.0.0/INSTALL_FOR_AGENT.md) 交给 Agent 即可安装；已有用户请明确要求升级。各平台安装包均有 SHA-256 校验文件。项目只在明确确认后创建公众号草稿，不自动群发。
