# 主题交付检查

设计完成后读取，作为兜底，不是创意菜单。创作和视觉评审标准只维护在 [主题创作流程](theme-design-review.md)；字段见 [主题包契约](theme-packs.md)，渲染、截图和复用命令见 [复核工具](theme-review-tools.md)。

## 1. 程序与证据

- 执行 theme validate，处理结构和 rehearsal 阻断。完整独立主题应覆盖全部 21 个布局角色；partial 补齐，品牌换色/明确局部范围另行注明。
- 核对 rehearsal.production 的正式渲染命中、资产和短长文结果。unchanged_template_roles 是原样模板提示，不是美观评分；在同次目视中区分有意简洁与未设计回退。旧核心缺少字段时用实际正式文章和试样对照，注明缺口。
- theme review 使用可安全使用的真实图片。主验收为手机视口 405px / 正文净宽 357px、校对视口 648px / 净宽 600px；净宽 320/390px 只是补充适配。按复核工具生成并实际打开同尺度总览、长短文与正常文章，不把视口和正文宽度混用。
- 内容、列表项、字段与图片绑定完整；换不同对象的比较/案例文案检查固定标签是否擅自命名。导读只在原文确有语义、正式渲染选中时出现，正常文章没有就独立试样补测。
- 新目录保存版本、哈希、报告与修订证据，不覆盖失败结果。交付链接优先使用 --article 生成的实际受检页面；自写导航必须切换匹配 profile 的文档，不能只改 iframe 宽度而漏掉字号缩放。

局部修订按差异使用 --roles，仍测所选角色长短文和全部档位；共享令牌/渲染变化扩大范围。局部报告不代表整套通过，不拼旧截图。定版省略角色筛选，做一次当前版本全量回归；程序校验与覆盖不省略。工具缺失时做可完成的等价检查，记录范围，不要求普通用户装开发环境或伪报执行。

## 2. 实际看图与修订

按创作流程在同次评审判断阅读与构图。原尺寸局部和长文看细节，正常文章看首中尾节奏，全页缩略图只看节奏。正文未用角色由全组件试样补看；好片头、相框或 geometry=pass 不替关键正文通过。

| 对象 | 观察与处理 |
| --- | --- |
| 标题 | 文字/编号保持焦点，带原文编号的真实标题也测。孤字独行受字数、字号、标记占宽与内边距共同影响，是复核提示，不自动改标题；先看主尺寸所有同类标题，不能缩字、插硬换行或只调一个标题碰巧过关。 |
| 长正文/比较 | 无溢出仍可能太窄或留下长空列。需要时让装饰只与标题同行、正文恢复全宽；比较按真实关系连接，不强制双栏或时间线。 |
| 列表/步骤 | 普通圆点、编号与首行同行，续行对齐正文，优先 marker_row；真分步卡片才上下分层。 |
| 图案/线/间距 | 图案加载、等比缩放、收口接缝、手机辨识和遮挡均需看。低矮边线图案可用 ornament_rule，大图另择位置不压扁；分隔用 rule，不用空正文。透明画布和累加边距不能制造大块空白。 |
| 图文 | 用真实图片看照片、框、角贴、图注和缩放，不遮主体、不添图片事实。原稿无图仍无图，独立试样检查图文角色。 |
| 全篇 | 遮住片头后正文仍有表达；分清招牌复用和整套套盒，保护特色并调整弱位置，不把删图案、去矩形当目标。安静正文/列表/图注服务阅读。 |

修订比较保持同文案、同图片、同宽度，说明缺失关系如何改善并查阅读回退；未解决的设计反馈不包装成“用户偏好待确认”。

## 3. 微信与交付状态

分别记录结构/覆盖、浏览器几何、实际目视与评审方式、用户偏好、微信保存后实测。21/21、零 findings 和 geometry=pass 都不是美观分，不编造还原率、成功率或平台认证；无看图能力保留未验证。

微信操作需授权，分别验 API 与复制：保存 → 重开 → 手机预览，覆盖小图案、透明 PNG 和实际正文配图。token、API 成功或粘贴瞬间正常不能代替保存后检查。正常文章未覆盖角色在独立全组件试样补测，复用生产渲染/交付，不改原稿或放宽预算。

回执绑定主题/渲染/文章或冻结版本、路径、核对阶段与范围、证据来源及未测项；设备、浏览器、深色模式未检查则保留未测。新增设计或共享代码变化按影响复测，不继承旧版全部通过，也不为凑轮次复测未变版本。

结构警告与实际缺陷分开。定位对应内容：无可见文字的线或图片容器零行高不等于正文叠字；可见文字继承零行高、缺图、遮挡或异常空白须修。渐变凹口仍需查边缘/深色模式。保存和手机正常的范围可通过并保留提示，不隐藏警告或为清零牺牲认可设计。没取得保存后 DOM 不把推测写成确定过滤规则。

旧冻结稿不静默更新，渲染变化需用户返回编辑、更新渲染并重新定稿；未知草稿按 [任务继续与交付](delivery.md) 人工核对。没有微信条件仍可交付完整本地主题，明确待测，不改核心 not_verified 字段伪造认证。
