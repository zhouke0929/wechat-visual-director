我需要准备什么？

WeChat Visual Director（公众号视觉主编）是开源的微信公众号 AI 排版 Skill 与本地工作台。使用能读取 Skill、执行本机命令的 Codex、OpenCode 等 Agent。Windows x64 正式支持，macOS 为 Technical Preview；项目仍处于 Alpha。

安装入口读取 main/VERSION 并核对已发布包。如果宿主只添加了 Skill，可继续说“打开公众号工作台”；自动接续取决于宿主执行能力。安装与维护指南 ↗

改稿、配图，下次接着做

600px 内容校对支持原文编辑，405px 手机预览同步修改；最近任务可按标题查找，换主题保留正文与图片，也可回到上一版样式。正文配图和封面区域有绑定当前任务的 Agent 指令；宿主支持原生生图时可生成待审核候选，也可接图片 API 或上传自己的图片。

复制图文可包含已采用的正文图片与主题装饰，无需微信 API；浏览器需支持，图片多时要等待处理，保存后核对手机效果。封面、标题等发布信息仍需在公众号后台设置。直传草稿才需接口权限、AppID、AppSecret、公网 IP 白名单及连接检测。无需另配文本模型 Key 不代表模型免费；图片与最终稿由你审核，不会自动群发。

Apache-2.0 开源。任务与配置保存在本机；交给 Agent、图片服务或微信的内容仍会发送到对应服务。密钥只填本地设置。本项目与腾讯、微信官方无隶属或背书关系。
