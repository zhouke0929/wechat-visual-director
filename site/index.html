ARTICLE-LEVEL VISUAL DNA

图片不是散装生成，
而是共享一份美术方向。

文章决定画什么、解释什么关系；主题系统决定色板、画材、表面语言和构图气质。正文插图与封面共享同一份 Visual DNA，生成后仍由运营人工确认。

01 / STRUCTURE

结构信息图

把步骤、对比和关系变成可扫读的画面，不把整段正文塞进图片。

02 / ATMOSPHERE

场景氛围图

用环境、人物动作和光线承接情绪，让图片服务叙事而不是只做装饰。

03 / METAPHOR

视觉隐喻图

用主题专属画材表达抽象观点，同时锁定原文事实与允许出现的短标签。

  1. STEP 01理解原文提取文章里的事实、步骤和语义关系
  2. STEP 02编译视觉方向按当前主题选择色板、画材与构图气质
  3. STEP 03运营确认后采用检查文字与画面，再进入正文或封面

WHY DIFFERENT

让模型负责理解，
让程序负责稳定。

01

先规划，再稳定渲染

Agent 输出受控的结构化规划，本地程序用组件完成 Markdown 转微信兼容 HTML；事实与来源仍由发布者核对。

02

主题服务内容关系

12 套主题、12 类语义组件与 6 类文章骨架，让并列、步骤、证据和对比拥有不同表达。换主题保留正文与已有图片，不自动重新生图。

03

你来编辑，你来确认

600px 内容校对支持原文编辑与自动保存，405px 手机预览同步修改。图片、封面与最终稿由你确认，预览差异仍需在实际微信端核对。

ONE CONVERSATION, ONE LOCAL WORKBENCH

从一个选题，到公众号草稿箱。

  1. 01提出主题或资料宿主 Agent 生成规范 Markdown 与视觉意图。
  2. 02打开本地工作台直接修改原文，切换主题，检查手机预览。
  3. 03人工确认关键资产可换主题、换图、裁封面或跳过不必要的图片。
  4. 04交付到公众号复制全文、下载交付包或调用官方 API 创建草稿。

BEFORE YOU START

开始之前，你可能想知道

01

已有 Markdown 或纯文本也能排版吗？

可以。把文章交给 Agent，它先整理结构、完成语义规划，再送入工作台。首页不提供绕过规划的直接上传入口。

02

Codex、OpenCode 能用吗？

安装器注册 Codex、通用 Agent Skill 目录与 OpenCode。宿主需支持读取 Skill 和执行本机命令；只有提供原生生图工具时，才可直接生成正文与封面候选。

03

必须配置 Key 或连接公众号吗？

排版无需另配文本模型 Key，但宿主模型使用仍受自身额度与收费规则约束。生图可用宿主工具、图片 API 或人工上传；连接公众号是可选项，未连接也能复制与导出。

直接创建草稿需要公众号具有相应接口权限，在本地配置 AppID、AppSecret 和公网 IP 白名单，并通过连接检测。未连接微信时，也可以复制排版后的内容到公众号后台，粘贴后核对图片。

程序采用 Apache-2.0 开源协议；任务与配置保存在本机，但交给 Agent、图片服务或微信的内容会发送到对应服务。API Key 与 AppSecret 只填本地设置，创建草稿不自动群发。本项目与腾讯、微信官方无隶属或背书关系。
