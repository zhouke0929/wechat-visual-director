# 主题阅读布局与参考扩展复核 · 2026-09-14

## 范围

根据用户对 `plume_arcade_page` 1.0.0 的反馈，修正标题主次、列表标记独占一行、边界装饰多占一排及单一图案过度重复。此次是主任务内的受控修订，不是独立盲测，不证明所有 Agent 都能达到相同审美结果。

## 共用能力与流程

- 核心新增 `marker_row`：受控小标记列与正文列同行，长内容在正文列内换行，编辑字段保持独立。
- 新增 `ornament_rule`：低矮 PNG 装饰与两侧细线共用一条装饰带，不使用绝对定位、负边距、calc 或正文图片化。
- 渲染器：`preview_renderer.v0.20.0-reading-layouts`。旧布局保持原样，旧冻结稿不自动更新。
- JSON Schema、运行时校验、默认完整主题骨架同步更新。
- Skill 的视觉复核增加关联候选与取舍、母题与重复图标的区别、阅读层级和同行/边界检查。增加两项评估用例；尚未执行新的独立 Agent 行为盲测，不将用例文件当成通过证据。

## 设计修订

参考沿用此前 Delaware Art Museum 收录的 Turbayne 装帧图片，不新增第三方素材或付费调用。源图在本地 `controlled-5/input/reference.jpg`。

- 羽片：选择弯曲线束，仅用于片头，去掉旧的放射羽眼。
- 拱廊：选择曲线门楣，用在证据重点区的边界，不成为每个标题上的图标。
- 烫金装订：选择低矮双卷线与双线边界，用于转场和问答边界。
- 章节与序列：由编号、字级和细线承担，不再把编号挤在大图案下面。
- 舍弃通篇重复孔雀眼、复杂整页底色和装饰性主题口号。普通段落、导语与列表保留安静区。

新主题 ID `plume_arcade_refined`，名称“羽拱书页 · 修订”，版本 1.1.0，完整 21 角色。旧主题与原稿保留；没有修改任何历史冻结文章。新包保存在忽略的独立测试目录，不作为官方主题发布。
