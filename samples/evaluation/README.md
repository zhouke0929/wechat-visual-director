# 公开评测样本

本目录只保留可以公开分发的合成稿、项目自建稿和结构边界夹具，用于验证 Markdown 解析、视觉规划、组件选择和回归测试。公开仓库不包含真实公司文章、后台导出、OCR 中间结果、二维码或品牌资产。

## 样本分组

- `visual-contrast/`：刻意设计为不同文章语义与结构，用于检查双方案和视觉系统差异；
- `structured/`：结构明确的组件覆盖夹具；
- `05-tutorial-steps.md`：教程步骤型完整样本；
- `06-weak-structure-boundary.md`：弱结构和保守降级边界；
- `v0.6-public-dev-set.json`：默认公开开发集；
- `v0.6-public-blind-manifest.json`：不依赖内部模型报告的盲评清单；
- `v0.6-recent-history-fixture.json`：最近五篇视觉避重的合成历史；
- `v0.6-visual-contrast-set.json`：视觉对比集定义。

这些内容仅用于产品与技术评测，不代表可直接发布的政策、招生或商业建议。涉及数字、政策和规则的文本均应在真实发布前由人工核验。
