# 参考转译流程对照 · 2026-09-10

## 基线判断

`plume_gilt_margin` v1.0.0：布局覆盖与本地结构检查通过，用户视觉验收未通过。主任务核对主题文件、实际文章与原始参考后，也未通过视觉验收。基线运行于本机 8032，本轮保留不覆盖。

主要差异：参考中的弯曲轮廓、层叠边饰与疏密关系，被过度简化为小图标、直线边框和浅色块；章节及正文重点组件缺少对应形态。基线说明提到的拱形关系未在自定义布局中有效体现。纯文字文章可检查阅读节奏，不能证明图片交付通过。这个结论不否定原有交付链路的技术测试。

## 本轮变更与控制变量

- 只更新 Skill 创作及视觉复核方法，不改引擎、Schema、节点预算、绘图原语、字体或交付代码。
- 同一原始参考图片、同一篇阅读习惯文章、同一开发核心、同一可用资源；隔离数据与主题 ID，预览端口 8033。
- 原任务继续执行，故这是有前次经验的同条件迭代，不是新的独立盲测，也不能将所有改善单独归因于 Skill 文档。新的独立用户场景需另测。
- 新方法集中在 `skills/wechat-visual-director/references/theme-design-review.md`；替换原有分散的抽象要求，主入口与主题契约均有明确路由。
- 设计 Agent 不收到主任务的具体造型答案，只收到原始参考、原稿、运行约束与新版 Skill。

## 结果生成前确定的验收问题

1. 参考的核心形态/空间关系是否在真实原型中出现，而非只在描述中存在？
2. 手机正常尺寸下是否清楚可辨，标题与正文是否保持主次？
3. 正文中段的高频标题与重点组件是否延续独立风格，而非只靠片头图标？
4. 组件是否按信息关系形成有联系的变化，而不是统一盒子换色或无关花样？
5. 是否有实际对照、自查差异和针对性修订证据？没有必要不强制修改次数。
6. 全套字段完整、长短文案和正常文章可读，未新增事实、不可编辑正文或未授权外部操作？

任何重要视觉目标未体现时，明确标记未达到，不以覆盖率、技术 findings 数量或自动满分抵消。读取失败或能力限制单列，不通过修改验收标准追认成功。
