# 自定义主题图文交付验收 · 2026-09-10

这是开发验收记录，不是所有主题的兼容性保证。

## 范围与证据

- 主题：`folk_papercut_lantern`（纸灯迎春）`1.1.0`。
- 文章：把课程作业整理成一份能讲清楚的作品集；本地任务 `42259e7f-5e10-4df5-a97b-1573ad13d8a0`。
- 本地正常文章覆盖 9 个布局角色：hero、lead、heading、concept_explainer、image_caption、logic_path、evidence_callout、subheading、action_checklist；另含两张既有 AI 配图。不代表其余角色已在这篇微信稿中验证。
- 间距修复渲染器：`preview_renderer.v0.19.1-rule-linebox`。用户最后复测的微信草稿标识与冻结版本未独立读取核实，不填入推测值。
- 微信证据来自本任务用户实际操作与反馈，Agent 未代为保存、发布或在手机端直接检查。

## 结果与历史

1. 用户此前确认正常文章复制图文可用、流畅，大图压力样本等待后可预览；这不等于任意大小图文都能流畅复制。
2. 本轮 API 最初在图片上传阶段返回 40113 / 40001。静态 WebP 上传格式转换、明确 token 拒绝时的有界恢复等修复后，用户确认“能顺利保存了”。获取 token 本身不作为草稿测试通过。
3. 随后用户提供微信保存后截图：导语虚线下多空行、章节标题下留白过大。本地向旧 rule 节点补入换行可复现额外行高；约束 rule 行盒后，在 320/390/600px 实验中尺寸稳定。此实验不是完整微信清洗器仿真。
4. 更新渲染、请用户重新确认最终稿并复测后，用户明确反馈“ok了，通过了”。据此将本轮报告的间距缺陷记为用户验收通过；不宣称对全部 21 个角色重新完成了双路径实测。

## 已固化的防回归边界

- 主题声明采用受控 rule/drawing，行盒与线稿图片化由核心处理，Agent 不逐主题添加定位补丁。
- 普通复制图文不依赖公众号凭据，正文图片和小装饰都属于交付资产；保存后效果须与 API 路径分开记录。
- 核心渲染更新不静默改写冻结稿或微信历史草稿。
- 自动化验证源码：`apps/api/tests/test_theme_rule_spacing.py`、`apps/api/tests/test_wechat_upload_recovery.py`。结构断言和本地模拟不替代微信实测。

下一次独立主题盲测应使用新的参考与正常文章，检查流程能否自行完成；其微信状态重新从待实测开始。
